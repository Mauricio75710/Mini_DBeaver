## Instrucciones 
Elabora, en equipos de máximo 4 integrantes una aplicación de escritorio en Java que realice las siguientes tareas:
Debe tener una pantalla de inicio de sesión, en la cual se deben poder colocar un host, nombre de usuario y contraseña
Con las credenciales introducidas en el login, debe abrir un túnel SSH al host proporcionado, usando el usuario y contraseña.
Con el túnel SSH, debe conectarse a la base de datos its5a presente en el host, y obtener un listado de tablas en dicho esquema.
Al seleccionar una tabla, los registros presentes en dicha tabla deberán guardarse de manera local en el equipo donde se ejecute la aplicación en una base SQLite.
Una vez que la base SQLite ha sido "descargada" del host, debe permitir realizar las operaciones CRUD básicas en la misma.
Para tener la calificación completa, la aplicación debe implementarse respetando el patrón de diseño MVC respetando claramente las responsabilidades de cada parte. Las aplicaciones en JavaFX tendrán una calificación más alta que las aplicaciones realizadas en Swing.

La entrega se realizará mediante un repositorio público de GitHub, el cual debe tener una carpeta llamada Screenshots en dónde tengan capturas de pantalla de la aplicación en funcionamiento. Si el repositorio no cuenta con esta carpeta, la calificación obtenida se dividirá a la mitad.

El día martes 3 de noviembre, algunos equipos presentarán sus aplicaciones en clase, lo cual contribuye a su porcentaje de calificación de exposiciones.

Si un trabajo en equipo que no cuenta con lista de integrantes, sólo el que realice la entrega tendrá calificación.
